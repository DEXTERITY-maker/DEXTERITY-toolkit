# 🦸‍♂️ DEXTERITY v4.1 — современный инструмент для UserLAnd

**DEXTERITY** — это мощный bash-скрипт с красивым терминальным интерфейсом (на базе **Gum**), который помогает работать с русским языком, мониторить систему, чистить мусор, создавать бэкапы, анализировать сеть и даже общаться с AI.

## ✨ Новое в версии 4.1

- 🖥️ **Интерактивная приборная панель** — запуск `btop` для визуального мониторинга CPU, RAM, дисков и сети.
- 📊 **Визуальный прогресс-бар** при создании резервной копии.
- 🌍 **Расширенный аудит сети** — определение публичного IP и геолокации.
- 🧠 **AI-помощник** — задайте вопрос на русском, получите ответ или команду (через DuckDuckGo API).
- 📂 **Умная сортировка файлов** — автоматическое распределение файлов по папкам расширений.
- ⚙️ **Поддержка аргументов командной строки**:
  - `dexterity --backup` — создать бэкап
  - `dexterity --clean` — очистить систему
  - `dexterity --monitor` — запустить монитор
  - `dexterity --debug` — режим отладки
  - `dexterity --help` — справка
- 🔧 **Автоматическая установка рекомендованных пакетов** (например, `bash-completion`).

## ✨ Основные возможности

- 🇷🇺 **Полная поддержка русского языка** — настройка локали, перевод, проверка орфографии
- 📊 **Системный монитор** — реальная загрузка CPU, RAM, диска (через `/proc/stat`) + btop по желанию
- 🌐 **Аудит сети** — локальное сканирование + публичный IP и геолокация
- 💾 **Умный бэкап** — сжатие домашней директории с проверкой целостности и прогресс-баром
- 🧹 **Тотальная уборка** — очистка кэша apt, временных файлов и логов
- 🧠 **AI-помощник** — задайте вопрос, получите ответ (без ключей API)
