# 🦸‍♂️ DEXTERITY — многофункциональный инструмент для UserLAnd

**DEXTERITY** — это bash-скрипт, который помогает работать с русским языком, очищать систему, делать резервные копии, анализировать сеть и диск. Работает в окружении UserLAnd (или любом Linux-терминале).

## 📦 Возможности

### 🇷🇺 Русский язык
- Настройка русской локали
- Перевод текста (английский ↔ русский) через translate-shell
- Проверка орфографии в файлах (aspell)
- Транслитерация (русские буквы → латиница)
- Вывод текущей даты на русском
- Анализ русских символов в файле

### 🖥️ Системные функции
- Системный монитор (CPU, RAM, диск, процессы) с сохранением отчёта
- Тотальная очистка (кэш apt, временные файлы, логи)
- Умный бэкап домашней директории с проверкой целостности
- Аудит сети (сканирование активных устройств)
- Анализ диска (интерактивный ncdu)
