# 🦸‍♂️ DEXTERITY v4.0 — современный инструмент для UserLAnd

**DEXTERITY** — это мощный bash-скрипт с красивым терминальным интерфейсом (на базе **Gum**), который помогает работать с русским языком, мониторить систему, чистить мусор, создавать бэкапы и анализировать сеть.

## ✨ Особенности

- 🎨 **Современный дизайн** — анимированные спиннеры, прогресс-бары, цветные рамки (библиотека `gum`)
- 🇷🇺 **Полная поддержка русского языка** — настройка локали, перевод, проверка орфографии
- 📊 **Рабочий системный монитор** — реальная загрузка CPU, RAM, диска (через `/proc/stat`)
- 🌐 **Аудит сети** — автоматическое определение интерфейса и сканирование локальной сети
- 💾 **Умный бэкап** — сжатие домашней директории с проверкой целостности
- 🧹 **Тотальная уборка** — очистка кэша apt, временных файлов и логов
