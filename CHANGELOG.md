# Changelog

## [4.1.0] - 2026-05-31

### Добавлено
- Интерактивная приборная панель (btop)
- Визуальный прогресс-бар для бэкапа
- Расширенный аудит сети (публичный IP, геолокация)
- AI-помощник через DuckDuckGo API
- Умная сортировка файлов по расширениям
- Поддержка аргументов командной строки: --backup, --clean, --monitor, --debug, --help
- Автоматическая установка рекомендованных пакетов

## [4.0.0] - 2026-05-30

### Добавлено
- Первая версия с gum-интерфейсом
- Системный монитор, очистка, бэкап, аудит сети
