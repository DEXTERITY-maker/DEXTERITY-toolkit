# Changelog

Все заметные изменения в проекте "DEXTERITY" будут документироваться в этом файле.

## [3.0.0] - 2026-05-31

### 🚀 Главное обновление: Визуальный редизайн!

- **Профессиональный интерфейс**: Главное меню и все диалоги переписаны с использованием библиотеки `dialog`. Теперь скрипт выглядит как нативное консольное приложение.
- **Анимация загрузки**: Добавлены визуальные индикаторы (прогресс-бары и спиннеры) для всех продолжительных операций.
- **Расширенный системный монитор**: Теперь отображает загрузку CPU, RAM и диска в виде наглядных прогресс-баров.

### ✨ Улучшения

- **Автоматическая проверка**: Скрипт сам проверяет наличие нужных утилит и предлагает их установить.
- **Обработка ошибок**: Улучшена стабильность и информативность сообщений об ошибках.
- **Чистота кода**: Проведён рефакторинг, удалены дубликаты, скрипт стал легче для чтения.

## [2.0.0] - 2026-05-31
